# 关注记录与 Alpha 未读同步修复

版本：0.4.1（构建 5）。验证时间：2026-10-21 至 2026-10-22。

## 问题与修复

原关注页只显示需要回应的 `Attention`，没有读取 `Digest.related`，因此“与你相关但未要求回应”的摘要被遗漏。新增 `AttentionFeed`，默认同时显示找我的消息和相关摘要，支持分类筛选。已有相关摘要无需重新调用模型即可显示。相关摘要可以标记已阅，状态原子落盘后才更新界面，可在“包含历史”中回看。此状态与微信未读独立，不改变原来的回应通知、处理和稍后提醒语义。

原群列表的紫色小点来自历史摘要相关性，与 Alpha 未读无关。现在小点和数字只来自 `unread_count`；相关性显示为“与你相关”，摘要批数明确标为“批摘要”。尚未首次同步时显示未知状态，失败保留最后成功状态，并显示同步失败和刷新入口。

新增独立会话状态协调器：每次会话状态读取后等待 5 秒再刷新；暂停监听仍更新，打开窗口、恢复前台及系统唤醒也触发读取。消息补查、周期扫描和界面刷新共享同一账号的正在执行请求，避免慢请求覆盖新状态。切换账号或重连后，旧代次响应不再提交。未读字段缺失、非法或分页失败时拒绝整次更新；不变状态不重复保存完整快照或刷成功日志。
