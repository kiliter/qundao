# 群聊完整未读摘要验收记录

日期：2026-10-21。版本：0.4.0。

## 实际变更

即时缓冲和周期扫描只负责触发，共用按账号、群聊隔离的摘要任务池。每个任务执行时从 Alpha 重新分页读取完整未读快照；旧未读仍参与输入。以成功保存的快照末条去重，摘要结果与末条标记原子落盘。默认跨群并发 3，可在「关键词与规则」中调整为 1–8；缓冲默认 30 条、首条最长等待 3 秒，也可调整。

原有群聊白名单、双栏摘要/聊天、刘海、OpenRouter 自定义配置、落盘日志和日志阅读界面保留。日志补充缓冲原因、决策路由、周期末条比较、任务合并/并发/重试、快照范围和标记推进。原文日志提示保留在日志页。

旧版同步标识、已分析消息和部分摘要不转换为新成功标记；旧待处理消息迁移为新任务。升级后首次必要触发会重新整理当前完整未读。

## 自动化结果

最终常规回归：`swift test --scratch-path .build`，共 60 项，57 项通过、3 项真实接口测试默认跳过、0 失败。构建无编译警告。

| 验收点 | 自动化覆盖 |
| --- | --- |
| 无关实时消息不触发 | 本地批判断无关时任务池和模型调用均为 0；多条命中只提交一次 |
| 容量与固定时限 flush | 容量达到触发；连续新消息不延后首条截止；重复消息去重；缓冲落盘恢复、账号隔离 |
| M100→M101 全量上下文 | 第一次输入 100 条；同末条周期不调用；M101 后输入全部 101 条，包含 M1 |
| 统一来源去重 | 即时和周期同时入队一次执行；运行中多次触发只产生一次后续检查 |
| 同群串行、跨群有限并发 | 双槽并发测试；即时优先于等待周期；同群后续检查未变化时不再调用 |
| 新消息不误推进 | 模型运行时新增无关消息，不产生新触发，成功标记停在实际输入末条；相关新触发再次读取完整快照 |
| 失败与恢复 | 请求失败保留新触发、退避；取消、无效输出、落盘失败均不推进；运行状态重启恢复，账号不串号 |
| 原子落盘 | 实际临时目录写入/重读，结果、标记、任务同文件保存；权限 600，无残留临时文件 |
| 完整分页 | 501 条未读、相同时间戳、3 页稳定顺序；中途新增或已读边界变化重取；断页和循环游标失败 |
| Alpha HTTP 协议 | 注入 URLSession，真实客户端读取 401 条，校验游标、固定上界、服务器消息 ID |
| 超上下文 | 长中文/Emoji/转义字符消息完整拆分后还原一致；所有分段结果进入汇总；中途失败或非法汇总证据整体失败 |
| 既有功能 | @全员识别、自身发言排除、OpenRouter/TypeSafe 配置和模拟传输、聊天原文、日志分页/脱敏/大中文记录继续通过 |

## 真实接口验证

通过应用钥匙串临时注入 Alpha 凭据到测试进程，未打印或写入项目：

- Alpha 账号和群列表只读查询通过。
- 真实未读群以每页最多 2 条执行新快照加载器，通过完整分页、消息 ID 唯一性、末条与未读数量复核。
- 单独执行 `LiveTests`：4 项中 3 项通过、CPA 合成消息测试因测试进程未取得密钥跳过；0 失败。
- 用户完成应用的 macOS 钥匙串授权后，从 `/Applications/群岛.app` 执行「立即整理」：扫描 63 个群，7 个群产生完整未读摘要，消息数量分别为 1、2、3、5、5、12、69，共 97 条。CPA 7 次请求均 HTTP 200，7 份摘要与成功标记已落盘，任务池归零。
- 再次执行相同扫描：7 个群均因末条与成功标记一致跳过，其余 56 个群无未读跳过；CPA 总请求数仍为 7，没有重复摘要。
- 主窗口、设置滚动区、并发/容量/最长等待控件、双栏摘要/聊天入口和日志实时视图已检查。迁移保留原有 43 份摘要与 50 个即时白名单群。启动时钥匙串授权等待已移到后台，窗口不再被阻塞；用户已手动完成授权。

## 未完成的真实验收

- Alpha 没有提供原子未读快照或独立已读边界。当前采用“最新 N 条对应 N 条未读”的语义，分页前后复核 N 与末条。模拟测试覆盖并发变化；真实高流量、同时已读/收消息、数据库同步延迟仍需运行验收。校验失败会保留任务重试，不能宣称数据库级原子一致性。
- 本轮未重新验收真实 Jev 判断、长文本多层汇总的内容质量、连续运行和休眠唤醒场景。真实 CPA 单次完整快照摘要通过，不代表这些场景也通过。
- UI 验证仅针对安装后的设置入口、既有页面可访问和启动状态；不等同于所有刘海动画、所有屏幕尺寸的重新验收。
