## 当前结论速查

- 即时、周期、手动、补查和任务恢复都只处理白名单群。
- 私聊及白名单外消息入口丢弃，不缓存、不入池、不调用模型、不记录聊天原文。
- 即时消息只用于判断是否触发；摘要输入是执行时该群的全部未读。
- 相同成功末条不重复摘要；下一次有新增时，旧消息只要仍未读就继续作为上下文。
- 找我提醒与相关摘要统一进入「需要关注」，刘海显示同一关注流。
- 本地已阅与 Alpha / 微信未读互相独立；一键已阅不修改微信状态。
- Alpha 直接 HTTP REST，推送 HTTP SSE；CPA 与 Jev 保留各自直接 HTTP 调用。
- 最近一次未读同步质疑已由用户确认属于 Alpha 问题并要求停止排查；群岛未因此改代码。

## 阅读与维护方式

页面中的「已确认规则」表示用户决定，「当前实现」表示代码事实，「历史验证」表示某次验收记录，「未验证」表示不能据此承诺实际效果。若它们不一致，应记录差异并按用户最新要求处理，不要静默改写需求。

后续变更同时更新对应专题和必要的决策记录；测试统计注明日期及版本。仓库文档只使用合成账号、群和消息示例，不复制真实令牌、聊天正文或业务联系人资料。
