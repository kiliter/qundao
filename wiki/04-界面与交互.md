## 已确认的总体设计

原生浅色主窗口、菜单栏快捷操作、黑色刘海面板，刘海参考 Vibe Island。主窗口提供需要关注、群聊摘要、监听群聊、关键词与规则、刘海与通知、连接与模型、运行日志。

设计与修改时保证实际可视面积和滚动能力，不能出现原型或面板内容超出窗口却无法滚动的问题。新增完整页面或大幅调整交互时，延续先确认高保真原型再实施的方式；既有小修直接在原组件内完成。

## 统一阅读

群聊摘要和需要关注共享“左侧群列表、右侧摘要内容”的结构（刘海自 2026-10-22 起改为逐行列表，见下文）。右侧固定以摘要卡片阅读，点击「查看原文」弹出对应批次聊天记录，原文支持滚动和文本选择。

这取代了早期的“右侧摘要 / 聊天两种视角切换”。不要同时恢复一套重复入口或另写不一致的原文组件。

| 组件 | 责任 |
| --- | --- |
| [ConversationBrowser](../Sources/Qundao/Views/ConversationBrowser.swift) | 左侧搜索、群列表、选择保持和双栏布局 |
| [SummaryReadingCard](../Sources/Qundao/Views/SummaryReadingCard.swift) | 摘要正文、原文入口与已阅操作 |
| [SummaryPage](../Sources/Qundao/Views/SummaryPage.swift) | 群聊摘要列表、周期配置、生成未读摘要、本群已阅 |
| [AttentionBrowser](../Sources/Qundao/Views/AttentionPage.swift) | 主窗口的需要关注阅读流 |
| `ChatTranscript` | 原文聊天样式，按发送人区分，保留证据与定位 |

明确命中但模型尚未完成时，关注卡片可以先展示识别出的简述和原消息入口。不能因为缺少本地缓存就使「查看原文」无反应；摘要中保存的证据也是原文来源。

## 已阅操作与小点

| 位置 | 小点 / 数字表示 | 已阅范围 |
| --- | --- | --- |
| 需要关注、刘海 | 当前群本地待关注记录数 | 一键已阅处理当前账号全部待关注记录 |
| 需要关注的包含历史 | 仍只计算待关注记录，已阅或稍后记录不亮点 | 历史可回看，不自动恢复为待阅 |
| 群聊摘要 | 「微信 N」来自 Alpha；摘要批数另列 | 一键已阅处理当前摘要筛选范围；另有逐条、本群已阅 |
| 菜单栏与侧栏 | 与统一关注流相同的待关注总数 | 不另维护第二套计数 |

同群被较新摘要完整覆盖的旧摘要不计数；并入摘要的「找你 / 需回应」以卡片标签显示、不另计（规则见[消息与摘要流程](02-消息与摘要流程.md)「同群摘要覆盖」）。

所有已阅操作仅修改群岛本地状态，不写回微信，不推进摘要成功标记。批量操作捕获点击时的记录 ID，后到内容保留待阅。搜索群名只是定位，不能擅自改变“一键已阅”的已确认范围。

摘要排序使用消息时间：有 Alpha 未读的群优先，按最近活动时间倒排；其余按证据中最新消息时间，旧摘要没有证据才回退生成时间。不能让模型完成速度决定消息顺序。

## 群聊白名单

监听页用表格，保留群名、微信未读、即时识别和最近摘要等列，支持排序、搜索和多选移出。默认不自动加入全部群。

「添加群聊」窗口打开后直接列出全部可添加群，搜索仅缩小结果；提供全选当前列表和清空选择。用户无需先搜索才能发现群。文案明确白名单同时约束即时、周期和手动摘要。

## 刘海和菜单栏

- 刘海默认显示统一「需要关注」，无关摘要不进入面板。
- 2026-10-22 起刘海不再嵌入主窗口双栏缩小版，改为逐行列表：每行一个有待阅内容的群，显示群名、待阅数、时间，并直接完整显示本群每条待关注摘要（不截断）；面板高度随内容增长，仅超过屏幕可用高度时滚动。点击行打开主窗口「需要关注」并选中该群（AppStore.attentionGroupID），原文在主窗口卡片中查看；悬停可本群已阅。列表只含待阅记录，不提供「包含历史」。
- 支持悬停展开、点击固定和移出延迟收起；固定阅读时新内容不抢走所选群。
- 2026-10-22 起刘海显示处理状态（原型 prototype/刘海状态.html）：收起态左翼按阶段切换图形与短标签——空闲绿点、缓冲倒计时环与剩余秒数（截止按首条到达固定）、Jev 跳动省略号、读取 / 摘要转圈、排队灰点、退避橙色箭头与剩余秒数、新增关注勾号与计数跳动；处理中两翼加宽，空闲恢复设定宽度。展开后标题下显示「缓冲 → Jev 判断 → CPA 摘要」流水线，各阶段并行时分别点亮，并列出涉及的群（仅群名与条数，不含正文）；空闲时隐藏。正在摘要的群行显示「正在更新」。状态来自 AppStore.activity（缓冲区、decisionBatches、SummaryCoordinator 任务与本次摘要进度），减少动态效果时不播放循环动画。
- 刘海 P5 风格（2026-10-22，原型 `prototype/刘海P5风.html`，取代同日的浅色群卡片方案）：贴摄像头的收起条保持纯黑；展开面板为红 / 黑 / 白三色，背景含右上红色斜块、网点与左下红斜纹（静态绘制）。
  - 标题「需要关注」为剪报拼贴字，旁边黑色爆炸星显示待阅数（新增时弹跳）；右侧斜切「固定 / 收起 / 一键已阅」。
  - 状态条：斜切状态牌，状态名为「空闲 / 缓冲中 / Jev 判断（未启用 Jev 为「本地识别」）/ AI摘要 / 排队中 / 失败重试 / 新关注 / 已暂停」，切换时从左侧打出；右侧三段箭头「缓冲中 › Jev 判断 › AI摘要」按实际并行情况分别点亮；缓冲时显示红色倒计时条。
  - 收起态：左侧红色四角星徽记（处理中旋转、空闲为灰、失败反向慢转）+ 斜切红标签（倒计时秒数、Jev、AI 等）；右侧斜体待阅数。
  - 群卡片：每群一张歪斜白卡带红色错位阴影；**默认只显示最新一条摘要**，「还有 N 条较早摘要」可在卡内展开 / 收起；悬停翻成黑底并出现红色「本群已阅」；点击后盖「已阅」印章并斜切移除；正在摘要的群显示「更新中」与红色扫光。
  - 新关注时红色斜横幅「有人找你！ / 新的关注！」插播一次。减少动态效果时关闭旋转、扫光、插播与移除动画。
- 收起与展开宽度在设置中分别可调，避开摄像头区域；外接屏或无刘海屏幕居中定位。
- 当前展开默认宽度 440 pt，可调 360–680 pt；收起宽度按屏幕安全区域计算。
- 展开 / 收起动画（2026-10-22 性能优化后）：黑色形状是 `CAShapeLayer` 遮罩，用 `CASpringAnimation` 在渲染服务器上插值，主线程不逐帧参与；工具条与展开内容是两个独立的 `NSHostingView`，尺寸在动画中不变，展开内容常驻（收起时 alpha 为 0、不接收点击、不暴露给辅助功能），淡入淡出用图层 alpha 动画。面板先放大到外包络，形状稳定后再收缩；透明区域不响应点击和悬停。屏幕参数缓存，只在屏幕变化或唤醒时重算。尊重系统减少动态效果。
- 列表高度在测量视图内用 `onChange` 回报：preference 在独立宿主中不能从 `ScrollView` 内容向外传递；内容宿主也不能设为 `isHidden`，否则不排版、测不到高度。
- ⇧⌘I「显示 / 收起刘海」再按一次收起。
- 待阅记录在 `AppStore` 按快照缓存（`pendingAttention`），避免每次刷新多处重复过滤排序。
- 菜单栏保留打开窗口、显示关注、开始 / 暂停监听、免打扰、生成未读摘要及配置入口。

实现：[NotchController.swift](../Sources/Qundao/Services/NotchController.swift)、[IslandSizeControls.swift](../Sources/Qundao/Views/IslandSizeControls.swift)。

## 主窗口页面切换

- 每个页面首次访问时创建独立的 `NSHostingView`（`ContentView.swift` 中的 `PageContainerView`），之后切换只改 `isHidden`，不重建表格和文字排版。首屏显示约 1.5 秒后逐个预建其余页面（每个之间让出主线程），首次进入也不必现建视图树。SwiftUI 的 `opacity(0)` 会摘下并重新挂载隐藏页面的 AppKit 子视图，不能用于保留页面。
- 隐藏页面通过环境值 `pageActive` 得知自己不可见：日志页暂停实时读取，连接页与 Jev 卡片在重新显示时从当前配置刷新输入框。
- 状态栏、侧栏底部状态和工具栏拆成独立小视图，推送 / 同步状态变化只刷新这些区域。

## 日志阅读体验

来源筛选、入参 / 出参 / 错误视角、复制、内嵌 JSON 展开、换行、25 / 50 / 100 条分页和归档入口都需保留。

日志落盘成功后触发实时刷新；跟随最新时滚动到最新记录。用户选择或滚动查看旧内容时暂停跟随，但最新页继续接收记录并保持详情稳定。历史页收到新日志提示，点击可回到最新；不要在后台刷新时强制跳页。

界面必须提示诊断日志包含聊天原文，密钥已隐藏。实现见 [LogsPage.swift](../Sources/Qundao/Views/LogsPage.swift)。

- 偏好设置三页（关键词与规则、刘海与通知、连接与模型）由 AppKit `SettingsScrollView` 承载：文档视图按 SwiftUI 回报的内容高度定尺寸，滚动不触发 SwiftUI 排版；文档宿主关闭 safeAreaRegions，避免滚动移动原点时被当作安全区变化。主窗口隐藏页面从窗口卸下（宿主与 SwiftUI 状态保留），否则日志实时刷新等会让隐藏页每帧参与排版。刘海工具条、倒计时环与流水线的时钟只在缓冲 / 重试倒计时时运行；多个尺寸变化在 16 ms 内合并为一次形状动画。
