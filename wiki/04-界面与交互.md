## 已确认的总体设计

原生浅色主窗口、菜单栏快捷操作、黑色刘海面板，刘海参考 Vibe Island。主窗口提供需要关注、群聊摘要、监听群聊、关键词与规则、刘海与通知、连接与模型、运行日志。

设计与修改时保证实际可视面积和滚动能力，不能出现原型或面板内容超出窗口却无法滚动的问题。新增完整页面或大幅调整交互时，延续先确认高保真原型再实施的方式；既有小修直接在原组件内完成。

## 统一阅读

群聊摘要、需要关注和刘海共享“左侧群列表、右侧摘要内容”的结构。右侧固定以摘要卡片阅读，点击「查看原文」弹出对应批次聊天记录，原文支持滚动和文本选择。

这取代了早期的“右侧摘要 / 聊天两种视角切换”。不要同时恢复一套重复入口或另写不一致的原文组件。

| 组件 | 责任 |
| --- | --- |
| [ConversationBrowser](../Sources/Qundao/Views/ConversationBrowser.swift) | 左侧搜索、群列表、选择保持和双栏布局 |
| [SummaryReadingCard](../Sources/Qundao/Views/SummaryReadingCard.swift) | 摘要正文、原文入口与已阅操作 |
| [SummaryPage](../Sources/Qundao/Views/SummaryPage.swift) | 群聊摘要列表、周期配置、生成未读摘要、本群已阅 |
| [AttentionBrowser](../Sources/Qundao/Views/AttentionPage.swift) | 主窗口与刘海共用的需要关注阅读流 |
| `ChatTranscript` | 原文聊天样式，按发送人区分，保留证据与定位 |

明确命中但模型尚未完成时，关注卡片可以先展示识别出的简述和原消息入口。不能因为缺少本地缓存就使「查看原文」无反应；摘要中保存的证据也是原文来源。

## 已阅操作与小点

| 位置 | 小点 / 数字表示 | 已阅范围 |
| --- | --- | --- |
| 需要关注、刘海 | 当前群本地待关注记录数 | 一键已阅处理当前账号全部待关注记录 |
| 需要关注的包含历史 | 仍只计算待关注记录，已阅或稍后记录不亮点 | 历史可回看，不自动恢复为待阅 |
| 群聊摘要 | 「微信 N」来自 Alpha；摘要批数另列 | 一键已阅处理当前摘要筛选范围；另有逐条、本群已阅 |
| 菜单栏与侧栏 | 与统一关注流相同的待关注总数 | 不另维护第二套计数 |

所有已阅操作仅修改群岛本地状态，不写回微信，不推进摘要成功标记。批量操作捕获点击时的记录 ID，后到内容保留待阅。搜索群名只是定位，不能擅自改变“一键已阅”的已确认范围。

摘要排序使用消息时间：有 Alpha 未读的群优先，按最近活动时间倒排；其余按证据中最新消息时间，旧摘要没有证据才回退生成时间。不能让模型完成速度决定消息顺序。

## 群聊白名单

监听页用表格，保留群名、微信未读、即时识别和最近摘要等列，支持排序、搜索和多选移出。默认不自动加入全部群。

「添加群聊」窗口打开后直接列出全部可添加群，搜索仅缩小结果；提供全选当前列表和清空选择。用户无需先搜索才能发现群。文案明确白名单同时约束即时、周期和手动摘要。

## 刘海和菜单栏

- 刘海默认显示统一「需要关注」，无关摘要不进入面板。
- 支持悬停展开、点击固定和移出延迟收起；固定阅读时新内容不抢走所选群。
- 收起与展开宽度在设置中分别可调，避开摄像头区域；外接屏或无刘海屏幕居中定位。
- 当前展开默认宽度 440 pt，可调 360–680 pt；收起宽度按屏幕安全区域计算。
- 窗口尺寸动画与内容淡入协调，尊重系统减少动态效果；不能靠过宽面板掩盖排版问题。
- 菜单栏保留打开窗口、显示关注、开始 / 暂停监听、免打扰、生成未读摘要及配置入口。

实现：[NotchController.swift](../Sources/Qundao/Services/NotchController.swift)、[IslandSizeControls.swift](../Sources/Qundao/Views/IslandSizeControls.swift)。

## 日志阅读体验

来源筛选、入参 / 出参 / 错误视角、复制、内嵌 JSON 展开、换行、25 / 50 / 100 条分页和归档入口都需保留。

日志落盘成功后触发实时刷新；跟随最新时滚动到最新记录。用户选择或滚动查看旧内容时暂停跟随，但最新页继续接收记录并保持详情稳定。历史页收到新日志提示，点击可回到最新；不要在后台刷新时强制跳页。

界面必须提示诊断日志包含聊天原文，密钥已隐藏。实现见 [LogsPage.swift](../Sources/Qundao/Views/LogsPage.swift)。
