## 本地保存位置

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 应用状态 | `~/Library/Application Support/Qundao/qundao.sqlite`（SQLite，WAL，文件 600） | 群、消息缓存、关注记录、摘要（含原文证据）、Jev 待判断批次按记录存于 `records` 表；偏好、摘要标记与待办、实时缓冲、去重集合存于 `meta` 表。2026-10-22 起取代 `state.json`，首次启动在单个事务中导入后把旧文件改名为 `state.json.migrated` 备份 |
| 运行事件 | `~/Library/Application Support/Qundao/Logs/群岛-日期.jsonl` | 连接、同步、调度、耗时和错误，普通事件不记录聊天正文 |
| 诊断日志 | `~/Library/Application Support/Qundao/Logs/Diagnostics/诊断-日期-序号.jsonl` | 本地判断、Jev、CPA 的入参、出参及路由结果 |
| 凭据与模型 / 规则配置 | `~/.config/qundao/config.toml`，目录 700、文件 600 | `[alpha] token`、`[cpa] api_key/model/reasoning/concurrency/interval_minutes`、`[jev] method/api_key/base_url/api/model/threshold`、`[rules] names/keywords/semantic`；外部编辑自动重载，应用内修改写回。2026-10-22 前存于钥匙串 `cn.kiliter.qundao`，首次启动迁移一次后不再读取 |

目录使用 700、状态及日志文件使用 600 权限。文件权限限制访问，不等于状态和日志已经加密；原文内容不得随代码或排查材料公开上传。

## 状态与原子提交

[AppSnapshot](../Sources/QundaoCore/Models.swift) 保存 `preferences`、`groups`、`messages`、`attentions`、`digests`、`checkpoints`、`realtimeBuffer`、`decisionBatches` 及 `summaryState` 等字段。

`summaryState.jobs` 保存等待、运行和重试任务；`summaryState.markers` 保存成功摘要范围。消息去重、同步进度与成功标记是独立数据，不能互相替代。

[SnapshotPersistence](../Sources/QundaoCore/SnapshotPersistence.swift) 将临时文件写全并同步，再在同目录原子重命名。摘要完成通过 `AppStore.persistSummary` 把结果、完整证据、成功标记和任务状态作为一份候选状态提交；保存成功后才更新内存及通知。状态文件无法读取时停止写入，不能用空状态覆盖原文件。

当前摘要最多保留最近 500 个完整快照，但成功标记不随展示数量裁剪。其他缓存和日志的清理应遵循显式策略，不能为了排错直接删除 `qundao.sqlite`（及 `-wal/-shm`）或迁移备份。

## 白名单与迁移

入口校验在去重、缓存及缓冲前执行，拒绝消息不改变持久化字段。白名单群被移出时，当前账号相关处理缓存、缓冲、待判断批次、补查进度和摘要待办被清理，在途任务被取消。

不同账号的历史状态保留并隔离；切到某账号后重新按该账号当前白名单校验。旧版已完成摘要和历史日志不自动删除，也不当作待处理消息重放。

`alphaRESTVersion=1` 标记一次性 REST 迁移：旧 MCP 补查游标清空，消息 ID 去重和成功摘要标记保留。迁移必须幂等，不能每次启动清空有效进度。

## 必须保留的诊断信息

| 阶段 | 诊断内容 |
| --- | --- |
| 实时缓冲 flush | 容量 / 固定等待到期原因、消息数量、涉及账号与群 |
| 本地判断 | 输入消息、称呼与关键词、规则 / 语义结果、后续动作 |
| Jev | 实际输入、概率输出、阈值后的相关判断、分段和是否提交群任务 |
| 周期扫描 | 当前末条、成功末条、跳过或入队原因 |
| 任务池 | 来源、合并、排队、并发、重试、取消与完成 |
| 快照与 CPA | 首末范围、数量、实际模型输入输出、分段阶段、HTTP 状态及耗时 |
| 成功提交 | 保存后的成功末条，是否仍有待检查触发 |

模型请求开始和结果通过同一 `correlationID` 关联；`scope` 关联账号或群。实现见 [DiagnosticLog.swift](../Sources/QundaoCore/DiagnosticLog.swift)、[EventLog.swift](../Sources/Qundao/Services/EventLog.swift)。

日志按日落盘，单文件超过 10 MB 后滚动归档，历史不自动删除；追加后同步磁盘。日志 UI 只是阅读窗口，不是日志唯一保存位置。分页通过文件位置继续读取，新记录或归档不能打乱历史页。

## 敏感信息边界

诊断日志按用户要求包含白名单群原文和身份规则，UI 必须明确说明。白名单外原文不应通过拒绝原因、异常正文或迟到模型回调进入日志。

鉴权头不传入诊断记录；已知密钥、Bearer 字符串和敏感鉴权字段脱敏。Alpha HTTP 错误只记录路由与状态码，避免原始错误响应夹带正文或密钥。不要将真实聊天、账号标识或令牌写入测试夹具与 Wiki。

已经发送给模型的请求无法撤回；移出白名单后应阻止后续分段与迟到结果落盘，不能宣称已发送内容从服务端消失。聊天与模型输出永远是数据，不是应用操作命令。
